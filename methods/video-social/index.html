Video social, free first

This is a method. It is not an endorsement of any tool it names.

The picture is a motion page. A motion page is a static page: CSS and inline SVG, no script, no outside request, no video file in the repo. A person screen-records it. The recording stays on that person's machine. Nothing on this site hosts, renders, schedules or posts it.

Six steps, in order. A person does every step.
Step Who Check
1. Open the motion page A person Open /video. It runs sixteen seconds in a 9:16 frame and holds on its last card. Reload to play it again.
2. Draft the caption A free-tier model, then a person Paste the script text from /video into a model you already use. Ask for three caption variants and keep one. For every line ask: fact or story? A TrustShell line stays a fact. Do not mix them. This is the Laya method on /methods.
3. Run the verify command A person For each TrustShell line, run the verify command from /start on your own machine. Put what it printed in the caption. To show it on screen too, change the one receipt-line paragraph in video/index.html on your machine before you record. Never write a line the command did not print. Do not commit that change: the shipped page must say NOT_CHECKED.
4. Record A person Open /video#record, reload, and record with the screen recorder already on this machine. The Jev method on /methods applies: fail the cut unless it is 9:16 and the receipt line is present.
5. Read A person Read the picture and the words before anything is scheduled. A draft is not a post.
6. Schedule A person, in a free social tier Sign in to your own Metricool account. Schedule the clip, or leave it as a draft. Nothing here signs in for you.

Why the receipt comes before the schedule

A receipt line added after the clip is scheduled says nothing about what was read. The line is run and checked first, then recorded, then read, then scheduled.

What the shipped cut says

One TrustShell statement: this command is printed on the Start page. It makes no claim about what the command returns. So the receipt line on /video reads NOT_CHECKED, and that is the true line for this cut.

What this method does not do

  • It does not post. This site has no account and no form. Step 6 happens in the scheduler, by a person.
  • It has no result. No clip made with this method has been posted from here. There is no view, reach or click number, so none is printed. NOT_CHECKED.
  • It does not attest the clip. Provenance here means one thing: a person ran the verify command and the line it printed is in the cut. This site does not host, hash or sign the clip, and no attestation of the clip exists. NOT_CHECKED.
  • It does not say a plan is free today. On 2026-10-09 Metricool's help page on free and paid plans listed a Free plan with a monthly cap on scheduled posts. The cap changes, so this page does not repeat it. Read the current limit there. Metricool is named because it has a free tier. No relationship with Metricool is claimed.
  • It does not name a model. Any model you already use can draft step 2. Whether its plan is free, and its limits, are NOT_CHECKED here.
  • It does not state upload rules. Length, size and frame rules for each app are NOT_CHECKED here. Read the app's own help before you upload.

If someone filmed a clip, the phone clips and ffmpeg rows on the belt apply instead. This method needs neither. The rows for this method are on the belt too: a row with no link prints NOT_CHECKED.
