Motion page

This is a motion page. It is not a video file. It is CSS and inline SVG: no script, nothing loaded from outside this site, and no media file in the repo.

It plays once for sixteen seconds and holds on the last card. Reload to play it again. A person screen-records it. The recording stays on that person's machine.

Recording view hides the text around the frame. Reload once it opens. The method lists every step and who does it.

The script, as text

Every line is labeled. A fact line is about TrustShell. A story line is a stance of this site. They are different methods and are not mixed.

  1. story A name on a list is not a record. Three rows, each stamped NOT_CHECKED. (0 to 3.6 s)
  2. fact Check a claim yourself: trustshell verify "paste your own claim", the command printed on the Start page. (3.6 to 9 s)
  3. story No line, no claim. Claim, verify, receipt line. The receipt box is empty until a person runs the command. (9 to 12.8 s)
  4. Trust marketing. Static pages. No account. trustshell.dev. (12.8 s on, held)

The receipt line at the bottom of the frame reads NOT_CHECKED. This cut says nothing about what the command returns, so there is nothing to put there.

If your system asks for reduced motion, the frame shows only its last card and nothing moves. Turn that setting off before you record.
